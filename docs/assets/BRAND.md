# PERNAH Visual Identity Foundation

## Direction

**Symbol + Wordmark — The Continuity P**

The symbol combines a geometric **P**, memory nodes, and a continuous path. It is intended to express **Memory · Knowledge · Continuity** without relying on literal brain, book, cloud, database, leaf, or botanical imagery.

## Core palette

- Dark background: `#141414`
- Dark accent: `#2BEE34`
- Light background: `#F4F5EF`
- Light accent: `#176B1D`
- Primary text: `#141414` / `#F2F2F2`

## Typography

- Display / brand: **LEMON MILK**
- Interface / body: **Open Sans**

The web interface uses a font stack so the artifact remains standalone/offline-friendly. The lockup SVG carries the intended font family declaration; a licensed/bundled LEMON MILK font is intentionally not redistributed by this release.

## Variants

- `pernah-lockup.svg` — symbol + wordmark
- `pernah-symbol.svg` — symbol only
- `pernah-monochrome.svg` — monochrome lockup

## Semantic rule

The green accent is a **signal**, not a decorative flood. It marks active, connected, current, or actionable states.

## System reference

The cross-surface rules, tokens, interaction language, and surface-specific expression are defined in `DESIGN-SYSTEM.md`. The CSS token reference is `pernah-design-tokens.css`.
